# Trail (this repository)

This tree is **[Joeydekruis/trail-v2](https://github.com/Joeydekruis/trail-v2)**, an additive fork of T3 Code — not a clone for contributing back to [pingdotgg/t3code](https://github.com/pingdotgg/t3code).

**Never open a PR on `pingdotgg/t3code`.** Before any push or pull request, read [Pull requests stay on Trail](docs/operations/trail-maintainer.md#pull-requests-stay-on-trail). PRs and pushes go to **`origin` / `Joeydekruis/trail-v2` only**. Use `vp run trail:pr:create` or `gh pr create --repo Joeydekruis/trail-v2` — never bare `gh pr create`. Run `vp run trail:forge:ensure` after a fresh clone.
